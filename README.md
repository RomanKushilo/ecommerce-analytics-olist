# ecommerce-analytics-olist
Анализ продаж, клиентов и эффективности e-commerce

Главная задача

Провести комплексный анализ продаж, клиентского поведения и операционных показателей e-commerce-платформы, выявить факторы, влияющие на выручку и удовлетворённость клиентов, и разработать аналитический дашборд для мониторинга ключевых показателей.

Скачать исходные данные: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
